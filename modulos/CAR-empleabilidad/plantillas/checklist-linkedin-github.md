# Checklist · LinkedIn y GitHub

> Antes de que alguien te entreviste, busca tu nombre. Lo que encuentre es tu primera entrevista. Marca cada punto cuando lo hayas hecho; revisa la lista cada vez que termines un proyecto.

## GitHub
- [ ] Nombre real, foto sencilla y descripción de una línea («Data/AI engineer junior · Python, FastAPI, RAG»).
- [ ] **Perfil README** (repositorio con tu nombre de usuario) corto: quién eres, 3 proyectos con enlace, cómo contactar.
- [ ] **3–4 repositorios fijados**, los mejores, no todos. Los demás, archivados o privados.
- [ ] Cada repositorio fijado tiene: README con la plantilla de portafolio, licencia, `.gitignore`, `requirements.txt` o `pyproject.toml`, **CI en verde** y tests.
- [ ] Cero secretos en el historial (`git log -p` + herramienta de detección de secretos). Si hubo uno: revócalo, no basta con borrarlo.
- [ ] Commits con mensajes que se entienden y actividad reciente (no hace falta una racha diaria).
- [ ] Un `AGENTS.md`/`CLAUDE.md` en los proyectos hechos con agentes de código, con lo que revisas tú.
- [ ] Temas (*topics*) de cada repo con las palabras de las ofertas: `fastapi`, `docker`, `rag`, `mlflow`...
- [ ] Modelos o demos publicados (Hugging Face) con ficha del modelo si procede.

## LinkedIn
- [ ] Foto nítida, fondo neutro; banner sencillo.
- [ ] **Titular** con rol + evidencias, no «en búsqueda activa»: «AI Engineer junior · RAG evaluado, FastAPI, Docker · Madrid».
- [ ] **Extracto** de 4–6 líneas: qué haces, qué has construido (con enlace) y qué buscas. Primera persona, sin tópicos.
- [ ] Sección **Destacados** con los 2–3 repositorios o demos.
- [ ] **Experiencia** con las mismas viñetas que el CV (verbo + qué + cómo + resultado), incluida la experiencia no técnica relevante.
- [ ] **Aptitudes**: las 10–15 que aparecen en las ofertas y que defiendes; pide validaciones a compañeros y mentores.
- [ ] Ubicación y modalidad (híbrido/remoto) correctas; activa «abierto a trabajo» según tu situación (visible para reclutadores o solo para ellos).
- [ ] URL personalizada y la misma en CV, GitHub y correo.
- [ ] Idiomas y nivel real.
- [ ] Sigue a las empresas objetivo; escribe 1–2 publicaciones al mes contando lo aprendido en un proyecto (no «estoy encantado de anunciar»).

## Coherencia (lo que revisa quien te busca)
- [ ] Mismo nombre, mismos datos y misma historia en CV, LinkedIn y GitHub.
- [ ] Ninguna competencia en el CV que no tenga evidencia en un repositorio.
- [ ] Redes personales revisadas o privadas.
- [ ] Correo profesional y mensaje de bandeja de voz/disponibilidad sensato.

*Solicitudes y mensajes a reclutadores: personaliza (empresa, oferta y una evidencia tuya). Respeta las condiciones de uso de las plataformas: no automatices el envío masivo de candidaturas.*
