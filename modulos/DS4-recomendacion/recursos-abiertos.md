## Detalle de los recursos

### IIC3633 Sistemas Recomendadores, PUC Chile (diapositivas, edición 2026-2)
Curso universitario completo sobre sistemas de recomendación impartido por Denis Parra en la Pontificia Universidad Católica de Chile, con materiales en español. Es el mejor complemento en español para todo el módulo. Para la lección 6.1 mira la sesión de ranking no personalizado; para 6.3, *Item-based CF*; para 6.4, *Factorización matricial* (FunkSVD); para 6.5, *Implicit Feedback ALS*; para 6.6, *Métricas* y *Tests estadísticos*; y para 6.7, *Recomendación híbrida* y *FAccT* (justicia, explicabilidad y transparencia). La carpeta [`clases/`](https://github.com/PUC-RecSys-Class/RecSysPUC-2026-2/tree/master/clases) contiene el resto de temas (BPR, contexto, *bandits*, aprendizaje profundo).

### IIC3633 Sistemas Recomendadores, PUC Chile (grabaciones, edición 2020)
El README del repositorio de la edición 2020 enlaza las grabaciones de las clases en Google Drive, en español. Las más útiles para este módulo son: «Introducción», «Ranking no personalizado y FC», «Item-based FC», «Factorización matricial: FunkSVD», «Implicit Feedback CF» y la serie «Evaluación» (métricas de error y ranking; cobertura, diversidad y novedad; tests estadísticos). Son la alternativa en vídeo, en español, a los vídeos del curso. Los vídeos no indican licencia propia: enlázalos, no los descargues ni los vuelvas a subir.

### Recommenders (LF AI & Data Foundation)
Repositorio de referencia (originalmente de Microsoft) con notebooks de buenas prácticas sobre preparación de datos, modelos, evaluación y puesta en producción, casi todos sobre MovieLens. Para este módulo: *Estimating Baseline Performance* (por qué y cómo construir referencias, 6.2), *ALS Deep Dive* (teoría de la factorización y ALS en Spark, 6.4), *Evaluation* (RMSE, MAE, precisión, recall, NDCG, MAP y AUC con ejemplos, 6.6) y *Apply Diversity Metrics* (cobertura, novedad, diversidad y serendipia comparando ALS con un recomendador aleatorio, 6.7). Requieren instalar el paquete `recommenders` y, algunos, PySpark.

### Surprise
Librería de Python, con licencia BSD, para recomendadores con valoraciones explícitas: modelo de sesgos (*BaselineOnly*), variantes de k-NN (incluida *k-NN Baseline*, la versión con sesgos que implementamos en el notebook), SVD, SVD++ y NMF. Incluye MovieLens 100K como conjunto integrado y validación cruzada. Su README publica una tabla de resultados en MovieLens 100K (por ejemplo, RMSE 0,944 para el modelo de sesgos y 0,934 para SVD) que sirve para contrastar el ejercicio 4. Documentación: [surprise.readthedocs.io](https://surprise.readthedocs.io/en/stable/index.html) (enlazada desde el repositorio).

### implicit
Librería de Ben Frederickson con implementaciones rápidas (multihilo y GPU) de ALS para retroalimentación implícita, BPR, factorización logística y vecinos ítem-ítem. Es la forma más directa de practicar la lección 6.5 a escala. El README enlaza el artículo original de Hu, Koren y Volinsky en el que se basa el modelo de preferencia y confianza.

### TensorFlow Recommenders
Librería de Google basada en Keras para construir recomendadores con *embeddings* (la versión "neuronal" de la factorización de matrices). Su tutorial de inicio entrena un modelo de recuperación sobre MovieLens 100K. Útil si quieres conectar la lección 6.4 con el módulo 05 de *deep learning*.

### LightFM
Librería con licencia Apache 2.0 que representa cada usuario e ítem como la suma de los vectores latentes de sus características (metadatos). Así puede recomendar ítems y usuarios nuevos a partir de sus atributos: es exactamente la estrategia híbrida para el arranque en frío de la lección 6.7 y del ejercicio 1b. El ejemplo de inicio entrena sobre MovieLens 100K y evalúa con precisión@5.
