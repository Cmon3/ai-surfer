# N3-AI · AI Engineering (12 semanas)

Orientada a puestos como *AI/LLM Engineer*: post-entrenamiento, evaluación y producción de sistemas con modelos de lenguaje. Requisito: [N2 · Intermedio](../n2-intermedio/) o nivel equivalente.

**Certificado al completarlo:** *AI Engineering*.

**Requisitos de cómputo:** los notebooks de AI5–AI7 funcionarán con modelos abiertos pequeños (0,5–3 B parámetros) en una GPU gratuita de Google Colab (T4) o en la cuota semanal de Kaggle. Habrá un presupuesto opcional de GPU en la nube (orientativo: 20–50 €) para quien quiera entrenar modelos de 7–8 B.
