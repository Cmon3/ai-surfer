# N2 · Intermedio (10 semanas · ~8 h/semana)

El núcleo de machine learning. Es el programa original de 14 semanas, reorganizado y ampliado. Requisito: haber completado [N1 · Fundamentos](../n1-fundamentos/) o superar la prueba de nivel.

**Certificado al completarlo:** *Machine Learning Aplicado*.

## Criterios del certificado

- Completar ≥ 80 % de las entregas del bloque y aprobar el proyecto N2 según su [rúbrica](../../proyecto-final/rubrica.md).
