# N1 · Fundamentos (6 semanas · ~8 h/semana)

Primer bloque de la escuela. Para quien empieza desde cero o necesita una base sólida antes del núcleo de machine learning. Termina con un **proyecto integrador** que va al portafolio del estudiante.

**Certificado al completarlo:** *Fundamentos de Ciencia de Datos* (acumulable; ver [Programa](../../PROGRAMA.md) y [evaluación](../../docs/evaluacion-y-certificado.md)).

## Módulos

| Semana | Código | Módulo | Estado |
|---|---|---|---|
| 1–2 | F1 | [Python para datos](../../modulos/F1-python/) | ✅ Disponible |
| 2–3 | F2 | [SQL para análisis de datos](../../modulos/F2-sql/) | ✅ Disponible |
| 3–4 | F3 | [Estadística para la toma de decisiones](../../modulos/F3-estadistica/) | ✅ Disponible |
| 4–5 | F4 | [Matemáticas para ML](../../modulos/F4-matematicas-ml/) | ✅ Disponible |
| 5–6 | F5 | [Herramientas del oficio](../../modulos/F5-herramientas/) | ✅ Disponible |
| 6 | — | [Proyecto N1](proyecto/): análisis exploratorio completo (SQL + pandas + informe) | ✅ Disponible |

Los módulos 🚧 son nuevos; cuando estén listos llevarán los mismos materiales que los demás: README, apuntes, diapositivas, guiones, notebook, soluciones, cuestionario y recursos abiertos.

## Criterios del certificado

- Completar ≥ 80 % de las entregas del bloque y aprobar el proyecto N1, según la rúbrica del proyecto.
- Se puede empezar directamente en N2 superando la prueba de nivel (pendiente de publicar).
